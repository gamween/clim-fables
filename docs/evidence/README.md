## clim v1 (Ethereum Sepolia, TOKEN2049 Origins)

What shows that the clim risk desk ran as a Chainlink CRE workflow:

- `cre-reports-sepolia.json`: every `RiskReported` event emitted by the clim risk desks on Ethereum Sepolia since the hackathon kickoff (2026-10-06 04:00 UTC), with the transaction hash of each report written by `cre workflow simulate --broadcast`: 2,025 reports on the live desk `0xCDbfd6b9C0b97A8eE31706c6CDE5E54B4954334F` (collected at block 11862295, 2026-10-07 10:09 UTC; the loop keeps adding one about every 30 s) and 459 on the replay desk `0x4b843dc3A7ec6202d2337cdeF8C67a0F10f24746` (the finished replay of the 4 February 2026 storm). Generated by `docs/submission/src/collect-evidence.mjs`.
- `cre-simulate-*.log`: the workflow's own log lines (`[USER LOG]`) from single `cre workflow simulate --broadcast` runs on the live desk, one file per run, as the simulation loop recorded them: the four venues fetched, the consensus (median of each field), the desk's state before, `Write report transaction succeeded: 0x...` and `REPORT applied seq=...`. The loop keeps only these lines and any error line, so the CLI's own output (the simulator start, the trigger, `Workflow Simulation Result`) is not in these files; it stays in local logs. RPC keys and the local home directory are redacted. We kept only runs whose transcript ends with `REPORT applied`: the workflow's read-back of `RiskDesk.state()` at the latest block sometimes hits a lagging node of the public RPC and prints `NOT APPLIED` for a report that did land (about 5 % of the runs on 2026-10-06, logged in [`docs/sessions/2026-10-07.md`](../sessions/2026-10-07.md), Build notes; the next run's `desk before` line shows the report landed).
- [`bots/out/cre-runs.jsonl`](../../bots/out/cre-runs.jsonl): one line per run of the simulation loop (status, transaction hash, block, gas, forwarder result, decoded report). Since 18:47 UTC on 2026-10-06 a run is recorded `applied` from its receipt (the forwarder's `ReportProcessed` result true and a `RiskReported` in the same transaction); older lines keep the workflow's own status.
- [`bots/out/security-demos.jsonl`](../../bots/out/security-demos.jsonl): the forged-report demo (`bun run forge-report`, tx `0xadc28d17bde52a6b38627ed734783924876454005b6a7c5e7b3fda49f1fa6c02`: forwarder result `false`, no `RiskReported` in the forged transaction). An earlier forged `report()` from a throwaway key was refused the same way (tx `0x34ee46a6947d2831fdb3e5a09f831008589efd9cf099f61dca86dc4cdadc53d9`).
- Blind mode (circuit breaker): with the loop stopped, the live hook quoted the 30.00 bp safe fee (`quoteFee()` = 3000 pips, mode 2) 218 s after the last report (kill delay 180 s), and 500 pips, mode 0 again 16 s after the loop restarted (seq 16); logged in [`docs/sessions/2026-10-06.md`](../sessions/2026-10-06.md) (plan 04 Task 23 smoke test). On 2026-10-07 a local network outage stopped the loop twice (the CRE CLI checks its credentials on every run) and the hook charged at least 30 bp until reports resumed (friction log row 24). The replay hook `0xf6E4CEC98865A0B1D8b2D59f70a0A0036bF4D080` has quoted 3000 pips, mode 2 since the replay desk stopped reporting: `cast call 0xf6E4CEC98865A0B1D8b2D59f70a0A0036bF4D080 "quoteFee()(uint24,uint8)" --rpc-url https://ethereum-sepolia-rpc.publicnode.com`.
- A real storm, priced live: on 2026-10-07 the live desk's volatility reached 242.1 %/yr (report 1119, 02:11 UTC) and pool V's fee 26.50 bp, paid by a retail swap in the same block (tx `0xbc900e898c3ab4a46ea985d9d70786226c2edd7b6aefae2d566c8d8c280fe7e2`); the dashboard's [/replay](https://clim-zeta.vercel.app/replay#latest) recomputes it from these events.
- The README of the submitted version, section [Chainlink CRE evidence](https://github.com/DVB-ANS/clim/tree/token2049-submission#chainlink-cre-evidence), lists the latest reports with Etherscan links. All seven contracts clim deployed (its six own and the arbitrage router, Uniswap's unmodified `PoolSwapTest`) are verified on Etherscan and Sourcify.
